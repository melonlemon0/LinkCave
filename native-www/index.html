Link Fridge

The app normally opens https://linkfridge.app. If you are seeing this page, the remote site did not load (offline, DNS, or TLS). Check the connection and try again.

Developers: the shell defaults to that URL in capacitor.config.ts. To use another origin (for example local Next on port 3005), run CAPACITOR_SERVER_URL=http://127.0.0.1:3005 npm run ios:sync, then open ios/App/App.xcworkspace in Xcode.
